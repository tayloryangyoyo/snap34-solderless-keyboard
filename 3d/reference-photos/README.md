# 原型參考照片

這些照片記錄目前的免焊接觸結構概念。

原型使用 3D 列印鍵盤底座，並在底座上預留 pin 或 socket 的孔位。銅箔膠帶貼在孔位上方或周圍作為導電路徑。當 pin 壓入孔中時，3D 列印塑膠會微幅變形，並把 pin 持續壓向銅箔。
